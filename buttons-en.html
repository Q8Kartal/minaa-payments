Button

The base component: a capsule that fits its content, with a soft Jelly body. Everything below changes exactly one variable of this button.

Button with leading or trailing icon

Four content configurations. Appearance Primary and size 48px are fixed; the only variable is whether an icon is present and where it sits. Each configuration owns its width — no space is reserved for an icon that is not there.

Icon Button

Its own family, not a configuration of Button: a circular jelly-icon-button whose side equals the button height, and which needs an accessible name because it carries no text.

Appearances

Five appearances. Size 48px and the content configuration (leading icon) are fixed; the only variable is colour. Primary carries the key action and Secondary the secondary button — both mark hierarchy, not importance. Outline and Ghost are for a quieter supporting action.

Sizes

Three approved sizes. Appearance Primary and the content configuration are fixed; the only variable is height — and with it the horizontal padding, the text size and the icon size.

Button groups

Buttons side by side, separated by space-150. The primary action comes first in reading order, and a group holds no more than one primary. Colour here expresses hierarchy, not importance: blue Primary 700 for the key action, red Secondary 600 for the secondary button — as in the Colour Foundations.

Interaction and Jelly behaviour

Interaction state is entirely separate from configuration: hover, press and focus change neither the button's content nor its width.

  • Progress --p runs 0 to 1 and is read from Jelly's own deformation — no timer, and it never completes on its own.
  • Colour: starts at the real contact point, spreads the way the body leans, and retracts along the same path on release.
  • Touch: finger pressure is used where the device actually reports it; otherwise progress advances while the finger stays down.
  • Keyboard: tabbing to a button shows the colour in full, and it clears when focus leaves.
  • Width is unaffected by any of it: the colour is painted on a canvas and cannot move the layout.

Feedback

Buttons that fire jelly-toaster through jellyToast(). The buttons are identical — same appearance, size and configuration — and the only variable is the tone. Each carries the hue of the toast it fires: blue info, green success, yellow warning, orange error. A semantic colour is never a brand colour. And because Jelly adds a spoken prefix to every toast, meaning never rests on colour alone.

Direction — RTL and LTR

The only directional comparison on the page. Same appearance, same size, same configuration; the variable is direction. The leading icon follows the start of reading, and the spacing does not change.
